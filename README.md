# IBASHO STATIONERY
### Android Application — Installation & User Guide

IBASHO Stationery is an e-commerce application where users can browse stationery products, add items to their cart, place orders, and pay securely through Xendit.

## 1. Requirements

Before installing the application, make sure you have:

- An Android smartphone
- The `app-release.apk` file
- A stable internet connection
- Enough available phone storage

**Note:** The application requires a working backend server for products, orders, and payments.

## 2. How to Install the APK

1. Download or transfer `app-release.apk` to your Android phone.
2. Open **Files** or **File Manager**.
3. Locate and tap `app-release.apk`.
4. If prompted, allow **Install unknown apps** for your file manager.
5. Tap **Install**.
6. Once installed, tap **Open**.

**Security reminder:** Only install APK files provided by the official project team. Disable the unknown-app installation permission afterward if no longer needed.

## 3. How to Use IBASHO Stationery

### Step 1 — Create an Account
1. Open the IBASHO Stationery app.
2. Tap **Sign Up**.
3. Enter your username, email, and password.
4. Complete the registration.

### Step 2 — Log In
1. Enter your registered username or email.
2. Enter your password.
3. Tap **Login** to access the application.

### Step 3 — Browse Products
1. Explore the Home page.
2. View stationery products and categories.
3. Select a product to view its details.

### Step 4 — Add Products to Cart
1. Choose the products you want.
2. Tap **Add to Cart**.
3. Open your Cart to review selected items.

### Step 5 — Checkout
1. Go to your Cart.
2. Tap **Checkout**.
3. Enter your contact and delivery information.
4. Review the total amount.
5. Tap **Continue to Xendit**.

### Step 6 — Complete Payment
1. The Xendit payment page will open.
2. Choose an available payment method.
3. Follow the payment instructions.
4. Complete the payment.

**Note:** In Test Mode, payments are simulated and no real money is transferred.

### Step 7 — Check Your Order
1. Return to the IBASHO Stationery app.
2. Wait for payment verification.
3. Once verified, the order will display **Paid**.
4. Visit **Orders** to view your order information.

## 4. Other Features

- **Categories** — Browse products by category.
- **Wishlist** — Save favorite products.
- **Cart** — Manage selected products.
- **Orders** — View order details and payment status.
- **Profile** — Manage account and personal information.
